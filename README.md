# Blackjack MVP (Expo)

React Native (Expo) multiplayer blackjack prototype.

## Quick Start

```bash
npm install
npm run start
```

Then choose a platform:

```bash
npm run ios
npm run android
npm run web
```

## Notes

- Built with Expo + React Native.
- Firestore is used for multiplayer state sync.
- Basic strategy advice is available in-game (if enabled).
